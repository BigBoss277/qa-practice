# API Practice

## Test Object

Postman Echo: `https://postman-echo.com`

## Goal

Practice basic API testing with Postman and document request / response behavior for a junior QA portfolio.

## Scope

- GET request with query parameters
- GET request with an empty query parameter
- POST request with JSON body
- POST request with empty JSON body
- GET request with special characters
- PUT request with JSON body
- PATCH request with JSON body
- DELETE request
- Negative case with an unknown endpoint and `404 Not Found`
- Basic DevTools Network observation

## Artifacts

- `postman-echo-collection.json` - importable Postman collection
- `api-test-cases.md` - documented API test cases
- `api-observations.md` - request / response observations and learning notes

## Skills Practiced

- API request methods: GET, POST, PUT, PATCH, DELETE
- Status code validation
- Query parameters
- JSON request body
- Empty body behavior
- Response body validation
- Negative API testing
- DevTools Network basics
